# Meng-Yen Page

## Run with XAMPP

This project now runs as a PHP site backed by MySQL through XAMPP.

1. Copy the repository to `C:\xampp\htdocs\Meng-Yen-Page`.
2. Start **Apache** and **MySQL** in the XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin` and import [database.sql](database.sql).
4. Open `http://localhost/Meng-Yen-Page/index.php`.
5. If your MySQL root account has a password, set `DB_PASSWORD` in
   [config.php](config.php).

The API in [api.php](api.php) uses PDO prepared statements and PHP sessions.
To create a login account, insert a user in phpMyAdmin with a bcrypt password
hash generated by `password_hash('your-password', PASSWORD_DEFAULT)`.

## Frontend development

Install dependencies with `npm install`, then run `npm run build` whenever the
frontend JavaScript or Tailwind styles change. This writes the browser bundles
to `dist/assets/`; Apache serves the PHP pages and API directly.
